# Admin Guide — Editing the Website

For the site owner. No technical knowledge needed.

## Signing in

1. Go to `yourdomain.com/en/admin/login` (or `/ar/admin/login`).
2. Enter your admin email and password.
3. After signing in you land on the homepage in **admin mode** — a gold toolbar appears at the top, and editable text shows a small pencil icon when you hover over it.

## Editing text

- Hover over any headline or paragraph → click the gold pencil (or click the text itself).
- Type your change. Press **Enter** to save (or click away). Press **Escape** to cancel.
- You edit each language on its own pages: text edited on the English site saves the English version, text edited on the Arabic site (`/ar`) saves the Arabic version.
- **Made a mistake?** If you've edited a piece of text before, a small circular-arrow icon appears next to the pencil when you hover over it. Click it to instantly restore that text to the original wording the site shipped with.

## Pricing plans (homepage)

- **Add Plan** creates a new card — fill in name, price, billing period, and features (type a feature, press Enter to add it).
- **Edit** on an existing card changes it; the trash icon deletes it (you'll be asked to confirm).
- Unticking **Active** hides a plan from visitors without deleting it.

## Teachers (About page)

- Add, edit, hide, or delete teacher profiles directly on the About page while in admin mode.
- Hidden teachers stay saved but don't appear to visitors.
- The avatar field takes an image *link* (URL), not a file upload — if you don't have one, leave it blank and the teacher's initials are shown instead.

## Programs (Programs page)

- Program names, descriptions, and subject lists are editable in admin mode on the Programs page.

## If you forget your password

You do not need to contact anyone — this is fully self-service:

1. On the sign-in page, click **Forgot password?**
2. Enter your admin email. If it matches the admin account, you'll receive an email with a reset link (check spam if it doesn't arrive in a few minutes).
3. Click the link and set a new password (minimum 12 characters).
4. Sign in with the new password.

## Changing your password anytime

While signed in, click **Change Password** in the gold admin toolbar. This works even if you already know your current password and just want to update it.

## Good to know

- Changes appear for you immediately. Visitors may see the previous version for a moment right after you save — it refreshes automatically.
- There is no draft mode: saving publishes right away. For big rewrites, prepare the text elsewhere and paste it in.
- Only one admin account should exist unless you deliberately create more (each one has full edit access).
- Sign out from the admin toolbar when done, especially on shared computers.
